# Native UI resources and hints: results

LPT-386–388 passed their approved Windows scope. The six window-first tools now expose bounded native resources, short snapshot hints, local inspection and exact hinted actions. CUA remains the only capture/input backend. The qualified runtime, permission policy and read-only geometry contract did not change.

## Evidence

- **Automated:** 214 unit tests, typecheck and 13 real-Pi tests passed. Real-Pi coverage uses a deterministic MCP peer for dense resources and zero-input rejection; it is not native Windows proof.
- **Native Windows:** two duplicate buttons remained separate. Local search, inspect, highlight and fresh element crop selected the exact second button. Five fresh hinted actions verified the counter, field value, checkbox, token-based scroll and control replacement in actual pixels and the fixture's read-only event log.
- **Owned browser:** the same production tools collected 46 native nodes. Duplicate search returned two candidates; document-scoped dense search reported 24 matches with eight returned. Fresh hinted click/value/toggle/replacement changed the exact fixture controls. Old aliases refused instead of rebinding.
- **Bounds:** small native walks reported truncation; explicit larger walks returned more nodes without claiming a complete tree. Reported screen and window-image bounds stayed distinct. Crop consumed input authority.
- **Images:** the final native annotated PNG was 500×426 with 29 visible labels. Exact raw and marked hashes were checked privately. Connectors no longer cross their target's text. Dense collisions, missing bounds and outside-image labels are reported.
- **Viewer:** the native hints switch affected later captures only. Disabling it delivered exact raw bytes; earlier marked bytes stayed unchanged. The raw/sent selector worked through native input after an explicit background refusal and fresh foreground request. The raw choice survived three read-only checks while polling continued. Stable card nodes preserve that choice until normal image eviction.
- **Human TUI:** the actual 77×57 viewport in pane w3E9:p7, revision3022, showed readable nested calls, a wrapped delivered receipt and the human-mark summary. Standard result/image details were collapsed; this is not an inline-image claim.
- **Cleanup:** only owned fixtures were closed. Their source/profile cleanup passed; Driver/helper process counts were zero and all mouse buttons were up. Existing Paint and game windows were preserved. The user's volatile image preference was restored through the viewer to 1024px/scale1.

Redacted counts and exact hashes: [evidence](evidence/ui-resources/run.json). Private screenshots, UI text, local URLs and target identities are not published.

## Honest limits

These native providers did not index the fixture group boxes or disabled button. The adapter preserves the reported document parent; it does not invent missing ancestry or a disabled alias. Partial-tree absence is unknown. Deterministic regressions cover disabled/foreign/consumed targets, cancellation, Safe denial, closed windows and uncertain receipts without changing live permissions.

Delivery is not proof of effect. A native combo-box value call returned delivered but did not change the selection. It was not replayed or counted as success; explicit supported keyboard input later verified the selection. Native screenshots and accessibility are not atomic.

The first DPI-unaware test fixture produced misaligned raw pixels. Its own thread awareness was fixed before creating controls, not through an OS setting. Live checks also found a label connector crossing a control and viewer polling replacing the focused selector. Both defects were reproduced, fixed, regression-tested, reloaded and checked through production tools.

No browser API, DOM/CDP, new CUA operation, cross-snapshot hint registry, alternate input backend or other epic work was added. Only the hint-label part of LPT-379 is included. Other work remains paused.
